# Organizanización de los repositorios

Para crear instlador.sh:
```text
1. nano instalador.sh      --> Escribes el contenido que quieras
2. chmod +x instalador.h   --> Da permisos para ejecutar
3. ./instalador.sh         --> Ejecuta
```

## 1. Eliminación .gitmodule, usaremos eurobot2027_software únicamente como índice no haremos conexiones de submódulos al resto de repositorios que serían los paquetes de ros2.

## 2. Contenido de instalador.sh:

Clona todos los repositorio de robot.repos dentro del repositorio central "WS_DIR="$(pwd)/eurobot2027_ws""
pwd indica la ruta actual en la que se ejeccuta el comando

Compila los paquetes instalados

## 3. Creación del paquete de SIMULACIÓN
   Para hacerlo desde cero:
   ### 1. 
   ros2 pkg create --build-type ament_cmake eurobot2027_software_simulacion --dependencies xacro robot_state_publisher ros_gz_sim ros_gz_bridge
   
   ### 2. 
   mkdir -p description launch config worlds

   ### 3. Cambiar el contenido de CMake:
   install(
    DIRECTORY description launch config worlds
    DESTINATION share/${PROJECT_NAME}
    )
   
   Como quiero usar el mismo repositorio tengo que borrar el paquete que hice de python y crearlo a mano en C++
   Para ello:
   ### 4. Editamos Package.xml (En el archivo del repo está comentado)

```bash
    <?xml version="1.0"?>
    <?xml-model href="http://download.ros.org/schema/package_format3.xsd" schematypens="http://www.w3.org/2001/XMLSchema"?>
    <package format="3">
        <name>eurobot2027_software_simulacion</name>
        <version>0.0.0</version>
        <description>Paquete eurobot2027_software_simulacion para Eurobot 2027</description>
        <maintainer email="ivan@todo.me">TnTivanTnT</maintainer>
        <license>Apache License 2.0</license>

        <buildtool_depend>ament_cmake</buildtool_depend>

        <depend>xacro</depend>
        <depend>robot_state_publisher</depend>
        <depend>ros_gz_sim</depend>
        <depend>ros_gz_bridge</depend>

        <export>
            <build_type>ament_cmake</build_type>
        </export>
    </package>
    
```

   ### 5. Creamos el archivo CMakelists.txt
    
```bash
    cmake_minimum_required(VERSION 3.8)
    project(eurobot2027_software_simulacion)

    # Comprueba que el compilador sea compatible
    if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
    add_compile_options(-Wall -Wextra -Wpedantic)
    endif()

    # Busca el motor de CMAKE
    find_package(ament_cmake REQUIRED)

    # Instrucción para copiar las carpetas al compilar dede /src/ a install/share/
    install(
    DIRECTORY description launch config worlds
    DESTINATION share/${PROJECT_NAME}
    )

    ament_package() 
```
   ### 6.  Crear las carpetas descrption, launch, config y worlds

## Carpeta meshes
Se añade la carpeta meshes en description para subir los archivos stl del modelo del robot, para sustituir: 
```bash
<box size="0.3 0.3 0.15"/>
```

Por:
```bash
<mesh filename="file://$(find eurobot2027_software_simulacion)/description/meshes/chasis.stl" scale="1 1 1"/>
```

Modificaremos el origen a 0,0,0 para que coincida con el del modelo (se podrá cambiar si se ve que no se mueve como corresponde).
Si la estrucutra es muy compleja tendremos dos archivos chasis_visual.stl detallado y chasis_colision.stl lo más simple posible.
Al exportar en el CAD debe ser en binario.
